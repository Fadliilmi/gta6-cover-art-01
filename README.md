An offline web app that turns your photo and a caption into GTA 6-style cover art — multi-panel poster, bold lettering, Vice City sunset/neon grade — exported as a PNG to share. Photos never leave the machine.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
